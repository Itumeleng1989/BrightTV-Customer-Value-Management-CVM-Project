An analysis of BrightTV user profiles and viewing transactions to identify opportunities to increase the subscription base, improve viewer engagement, and support the CEO’s subscription growth objective for the current financial year.

The project will use data analytics to answer four key business questions:
1. Who are BrightTV’s users? Understand user profiles, subscription behaviour, and audience segments.
2. How do users consume content? Identify viewing patterns, peak and low-consumption days, and usage trends.
3. What influences consumption? Investigate the relationship between user characteristics, content preferences, viewing times, and consumption levels.
4. How can BrightTV grow? Recommend content strategies, customer engagement initiatives, and acquisition campaigns to grow subscriptions.
The project translates analytical findings into practical recommendations for the CVM team, supported by measurable KPIs and an implementation roadmap
